# Third-party notices

The files `Almide-MIT.txt` and `Almide-APACHE.txt` reproduce the license texts from
[Almide at the release pinned by this repository](https://github.com/almide/almide/tree/v0.66.0)
(identical to those at the earlier source pin `852b028`).
Almide is offered under MIT or Apache-2.0, at the recipient's option. These notices
accompany the generated Wasm packages; our root MIT license does not replace them.

npm dependencies retain their own licenses and notices. Install dependencies from
the provider lockfile when preparing a function package, and retain those notices
when distributing them. This directory is not a complete dependency SBOM.
